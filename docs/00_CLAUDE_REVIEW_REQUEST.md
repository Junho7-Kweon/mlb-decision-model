# Claude 교차검증 요청서

## 목적

MLB 경기의 점수 확률분포를 데이터로 예측하고, 사용자 캡처에서 확보한 실제 배당과
결합해 유효 조합 Top 5를 추천하는 시스템의 설계 문서를 교차검증해 주세요.

이번 검토 단계에서는 프로젝트 코드를 수정하지 말고, 문서 사이의 모순·누락·위험과
권장 구현 순서만 제시해 주세요.

## 검토 자료 우선순위

1. `01_ARCHITECTURE_BLUEPRINT_V2.pdf` - 방향성과 모델·재학습 설계
2. `02_DATA_MODEL_ERD.md` - 목표 논리 ERD와 필드 정의
3. `03_PIPELINE_DRAFT.md` - 아직 본 프로젝트 문서에 확정 반영하지 않은 파이프라인 초안
4. `04_DATA_SOURCES_POLICY.md` - 허용 데이터 출처 정책
5. `05_PROJECT_README.md` - 현재 구현 상태와 실행 흐름
6. `06_DASHBOARD_FEATURE_SPEC.md` - 현재 대시보드 기능 명세

문서가 충돌하면 1번의 확정 방향성을 우선하되, 충돌 자체를 반드시 지적해 주세요.

## 확정된 핵심 원칙

- 모델 데이터는 배당을 만들지 않는다.
- 모델은 정규경기와 F5의 가능한 점수 결합분포 및 마켓별 적중확률을 계산한다.
- 사용자 캡처는 실제 마켓·기준점·선택 방향·배당을 제공한다.
- 모델확률과 캡처 배당은 추천 후보 생성 단계에서만 결합한다.
- 팀 기본전력, 팀 상대전적, 타자-투수 BvP는 서로 다른 피처다.
- 마켓마다 별도의 정산 규칙과 확률 변환 조건을 적용한다.
- 동일 경기 선택지끼리는 한 조합에 넣지 않는다.
- 추천 결과는 최대 Top 5 카드로 제시하되 기준 미달 후보로 강제로 채우지 않는다.
- 조합 실패를 모든 leg의 실패로 학습하지 않는다. 개별 leg와 점수분포를 정산한다.
- 결과는 batch로 누적한 뒤 challenger를 학습하고 검증 통과 시에만 champion을 교체한다.

## 집중 검토 요청

### 1. ERD

- PK/FK, 카디널리티, 중간 엔티티가 빠졌는지
- 시점별 스냅샷을 재현하기에 충분한지
- 모델 데이터·배당·추천·결과 라벨이 잘 분리됐는지
- 팀 상대전적과 BvP의 단위가 올바른지
- 점수 결합분포를 실제로 저장할 때 필요한 키가 충분한지

### 2. 모델

- Negative Binomial + GBDT 앙상블 방향이 현실적인지
- 정규경기와 F5 모델을 분리하는 것이 적절한지
- 점수 상관, 과산포, 극단 점수 꼬리 처리의 누락
- 확률 보정과 불확실성 추정 방식의 보완점
- 데이터 규모에 비해 과도한 모델이 포함됐는지

### 3. 마켓 규칙

- 승패·승1패·핸디캡·언더오버·홀짝·F5의 계산을 별도 규칙으로 관리하는 구조
- WIN/LOSS/PUSH/HALF_WIN/HALF_LOSS 등 정산 상태의 누락
- 연장 포함 여부와 공급자별 규칙 버전 관리
- push가 있는 경우 EV 계산이 이진 공식으로 잘못 단순화될 위험

### 4. 추천 엔진

- 점수분포에서 마켓확률을 구하는 방법
- 후보 필터와 동일 경기 배제 규칙
- 생존확률·EV·risk-adjusted EV 랭킹의 정의
- Top 5가 지나치게 유사한 조합으로 채워지는 문제와 다양성 정책
- 여러 경기 간 독립 가정의 한계와 보정 시점

### 5. 결과·재학습

- 개별 leg와 조합 결과의 올바른 라벨 분리
- 오류 원인 귀속이 자동화 가능한 범위
- 한 경기 결과에 과잉 반응하지 않는 batch 재학습 설계
- champion/challenger 승격 기준
- 모델 드리프트와 데이터 품질 경보의 누락

### 6. 현재 코드와의 간극

- 현재 코드에서 그대로 재사용할 수 있는 부분
- 폐기 또는 대체해야 할 구조
- 신규 모듈·스키마가 필요한 부분
- 한 파일씩 안전하게 수정할 수 있는 의존 순서

## 원하는 답변 형식

1. 전체 판정: 승인 / 조건부 승인 / 재설계 필요
2. P0, P1, P2 심각도별 발견사항
3. 문서별 모순과 누락
4. ERD 수정 제안
5. 파이프라인 수정 제안
6. 권장 구현 순서
7. 첫 번째로 수정할 파일 하나와 그 이유

각 발견사항은 가능하면 관련 문서명·섹션·엔티티명을 함께 적어 주세요.
